### LECCIÓN (estabilidad del server):
- **NO dejar múltiples instancias de server.js**: cada `Start-Process node server.js` crea una instancia; varias compiten por el puerto/offset y algunas quedan colgadas sin LISTENING → `ECONNREFUSED`.
- **Solución**: antes de iniciar, matar TODAS (`Get-CimInstance ... | Stop-Process`), luego iniciar UNA sola, verificar `netstat` muestre LISTENING y `curl /api/status` responda.
- `-WindowStyle Hidden` oculta errores. Para monitorear, iniciar con `-RedirectStandardOutput server.log -RedirectStandardError server.err.log` (server actual arrancado así).
- Server estable verificado: PID único, LISTENING, sin errores en stderr.
- Endpoint de prueba `POST /api/simular-boton {paso}` queda en server (equivale al callback del operador).
